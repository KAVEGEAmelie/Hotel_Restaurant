# Hotel_Restaurant

Application de gestion pour un **hôtel-restaurant** permettant de centraliser les opérations principales : gestion des réservations, des chambres, des clients et des services de restauration.

## 📌 Objectif du projet

Ce projet a pour but de fournir une base applicative claire pour :

- gérer les réservations de chambres ;
- suivre les informations clients ;
- organiser les services de restauration ;
- faciliter le pilotage quotidien d’un établissement hôtelier.

## 🚀 Fonctionnalités (prévisionnelles / à adapter selon le code)

- Gestion des chambres (état, disponibilité, capacité)
- Gestion des réservations (création, modification, annulation)
- Gestion des clients (profil, historique)
- Gestion restaurant (tables, commandes, menus selon implémentation)
- Tableau de bord de suivi des activités
